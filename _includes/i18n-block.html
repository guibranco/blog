{%- comment -%} Bilingual inline text block. Renders the Portuguese text visible and the English text hidden; the English span carries the `hidden` attribute in the server output, and assets/js/lang-switcher.js toggles the two on UI-language change. With JavaScript disabled the Portuguese text (the site default) is what shows. This is the same client-side swap the rest of the site uses for `[data-i18n]` elements — extended to arbitrary per-item content that would not belong in the _data/i18n.yml UI dictionary. Parameters: pt - Portuguese text (required; may contain inline HTML) en - English text (optional; falls back to `pt`) class - extra class applied to both spans (optional) {%- endcomment -%} {%- assign _ib_en = include.en | default: include.pt -%} {{ include.pt }}{{ _ib_en }}
