A Calculator (ADR-0015) whose figures come from the Post's front matter, not from a data file (ADR-0018): fx: from: AED # the trip's local currency to: EUR # the currency the Post converts into rate: 3.97 # how many `from` one `to` bought (1 EUR = 3.97 AED) as_of: 2022-04 # when that rate applied {% include calculators/fx-converter.html %} {% include calculators/fx-converter.html id="calc-b" %} (second copy on one page) Renders nothing at all when the Post has no `fx`.
